## 1. Overview

The Korg Z1's **Oscillator 1** supports **13 MOSS synthesis models**, including analog-style synthesis (`Standard`, `Ring Mod`, `Cross Mod`, `Sync`), spectral/formant shaping (`VPM`, `Resonance`, `Comb Filter`, `Organ`), and physical modeling (`Brass`, `Reed`, `Plucked String`, `Bowed String`, `Electric Piano`).

When you select a model with **OSC1 TYPE** (Slot 1), [`main.lua`](../../e1/z1-osc1/main.lua) dynamically reconfigures Slots `2..33`:
- Renames each active control to match the chosen synthesis model's parameter name in `PROG_PRM.TXT`.
- Switches each slot between a continuous **Fader** (`Controls 102..133`) or an enumerated **List** (`Controls 202..233`, such as `MODSRC1` modulation sources, `Wave Form`, `Brass Inst.Type`, or `Reed Inst.Type`).
- Adjusts parameter min/max ranges (including signed `-99..+99` parameters) and hides unused slots for models with fewer parameters.

## 3. Control Layout

- **Slot 1 (Control `1`):** `OSC1 TYPE` (`0..12` list overlay) — selects the active synthesis model and sends `F0 42 3g 46 41 01 2E 01 val 00 F7`.
- **Slots 2..33 (Controls `102..133` Faders / `202..233` Lists):** Dynamically bound to the active model's parameter definitions (`ExID = 1`, `id14 = 2048 + paramId`).
- **Per-Model State Retention:** Parameter values are cached per model in Lua (`modelValues[modelIdx][paramId]`) so switching models and returning preserves your edits on the Electra One.
