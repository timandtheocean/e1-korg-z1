# Page 4: Oscillator 1 (`OSC1`)

[← Back to the manual index](https://github.com/timandtheocean/e1-korg-z1/tree/main/usermanual/README.md) · [All manual pages](https://github.com/timandtheocean/e1-korg-z1/tree/main/usermanual/pages)

Oscillator 1 is the primary sound engine of the Korg Z1, offering **13 distinct synthesis algorithms** ranging from classic analog-style waveforms and FM/VPM to physical models of brass, reed, organ, electric piano, plucked string, and bowed string instruments.

Because each synthesis model has completely different parameters, the **OSC 1** page **dynamically morphs its controls, labels, value ranges, and layout** whenever you select a different **OSC1 Model**. Unused slots automatically hide so you only see the controls that actually shape the active algorithm.

> [!TIP]
> **Thin Faders for Modulation Depth:** Across the entire OSC 1 page, every modulation intensity (`Int`) control is displayed as a **thin horizontal fader**, making it effortless to tell modulation depths apart from primary tone controls.

## Screen Header & Quick Navigation (Row 1)

The top row is always available regardless of which synthesis model is selected:

| Slot | Control | Description |
| :---: | :--- | :--- |
| **Col 1** | **OSC1 Model** | Selects which of the 13 synthesis models Oscillator 1 uses. Changing models immediately reconfigures Rows 2–6 and updates the page title to show the active model name. |
| **Col 2** | **Init Wave / Form / Carrier** | Context-sensitive primary wave or exciter selector (appears for models that use a primary wave or form selector). |
| **Col 3–4** | **Edge / Mod Src & Int** | Primary timbre brightness (`Edge`) and its modulation source/intensity for the active model. |
| **Col 5** | **OSC Common** | Jumps directly to the [OSC Common](https://github.com/timandtheocean/e1-korg-z1/tree/main/usermanual/pages/03b-osc-common.md) page (where you can also save or load **OSC 1** and **Both OSCs** presets). |
| **Col 6** | **Jump OSC 2** | Jumps directly to the [OSC 2](https://github.com/timandtheocean/e1-korg-z1/tree/main/usermanual/pages/03-osc2.md) page. Note that OSC 2 is **disabled** while OSC 1 is set to Brass, Reed, Plucked String or Bowed String, because these models use both oscillators. |

## The 13 Synthesis Models of Oscillator 1

### 1. Standard OSC (`Standard`)
Classic virtual-analog waveforms (**Saw** and **Pulse**) with variable waveform symmetry (`Wave Edge`), Pulse Width Modulation (PWM), and sub-harmonic Sine/Warmth shaping (`Bottom`).
- **Row 1**: Model, Init Wave (`Saw`/`Pulse`), Wave Edge, Edge Mod Source & Edge Mod Int.
- **Row 2**: Waveform (`Type`), Level (Pulse Width / Symmetry), Mod1 Source, Mod1 Int, LFO1 Int.
- **Row 3**: Bottom (low-end sine reinforcement).

### 2. Comb Filter (`Comb Filter`)
Passes an impulse, noise burst, or external oscillator signal through a tuned resonant delay line to create metallic chimes, karplus-strong plucks, and resonant flanging tones.
- **Row 1**: Model, Input Select (`Impulse`, `Noise`, `Noise+Imp`, `OSC2`, `SubOSC`, `NoiseGen`), Wave Edge, Edge Mod Source & Int.
- **Row 2**: Feedback Level (resonance sustain), Mod1 Source, Mod1 Int, Damp (high-frequency decay damping).
- **Row 3**: Key Track, Fine Key Track (for precise high-register tuning).

### 3. Variable Phase Modulation (`VPM`)
A 2-operator FM / phase-modulation synthesizer inside a single Z1 oscillator, complete with its own internal modulator envelope, wave folders, and feedback loop.
- **Row 1**: Model, Carrier Wave (`Sine`, `Saw`, `Pulse`, `Tri`), Wave Edge, Edge Mod Source & Int.
- **Row 2**: Carrier Level, Feedback, Mod1 Source & Int, Modulator Wave.
- **Row 3**: Modulator Ratio (`Coarse`), Fine Tune, Key Track, Mod2 Source & Int, Modulator Level.
- **Rows 4–5**: Dedicated internal Modulator Envelope (`Attack`, `Decay`, `Slope`, `Release`, `Break Level`, `Sustain Level`, `Release Level`) plus envelope velocity and time/level key tracking.

### 4. Resonance OSC (`Resonance`)
Simulates up to four parallel formant bandpass filters excited by a base waveform—ideal for vowel pads, choirs, and talking synth leads.
- **Row 1**: Model, Wave (`Saw`/`Pulse`), Wave Edge, Resonance Level, Resonance Mod Source & Int.
- **Row 2**: Formant Base Cutoff, Frequency Width (spread between bands), Bandwidth, Key Track, Mod Source & Int.
- **Rows 3–4**: Individual Band 1–4 Center Frequencies and Band 1–4 Levels.

### 5. Ring Modulation (`Ring Mod`)
Multiplies Oscillator 1 with a carrier source (**OSC 2**, **Sub OSC**, or **Noise**) to produce clangorous, bell-like sum-and-difference sidebands.
- **Row 1**: Model, Wave (`Saw`/`Pulse`), Wave Edge, Edge Mod Source & Int.
- **Row 2**: Carrier Source (`OSC2`, `SubOSC`, `Noise`), Ring Depth, Depth Mod Source & Int, Low Boost.

### 6. Cross Modulation (`Cross Mod`)
Uses the audio output of **OSC 2**, **Sub OSC**, or **Noise** to modulate the frequency/phase of Oscillator 1 for gritty, aggressive harmonic textures.
- **Row 1**: Model, Wave (`Saw`/`Pulse`), Wave Edge, Edge Mod Source & Int.
- **Row 2**: Modulator Source (`OSC2`, `SubOSC`, `Noise`), Cross Mod Depth, Mod1 Source & Int, LFO1 Int.
- **Row 3**: Bottom (low-end weight).

### 7. Oscillator Sync (`Sync`)
Locks Oscillator 1's phase reset cycle to the pitch of **OSC 2** or **Sub OSC**, allowing classic screaming hard-sync sweeps when you modulate OSC 1's pitch.
- **Row 1**: Model, Wave (`Saw`/`Pulse`), Wave Edge, Edge Mod Source & Int.
- **Row 2**: Master Source (`OSC2`, `SubOSC`), Sync Timbre/Depth, Bottom.

### 8. Organ Model (`Organ Model`)
An additive drawbar tonewheel/pipe organ model with three customizable harmonic partials and key-click percussion.
- **Row 1**: Model, Base Drawbar Config, Percussion Switch, Perc Harmonic, Perc Decay, Perc Key Track.
- **Rows 2–4**: Drawbars 1, 2, and 3—each with its own Harmonic Ratio (`2'` to `16'` plus mutation harmonics), Wave (`Sine`/`Tri`), Fine Detune, Level, and Level Mod Source & Int.

### 9. Electric Piano Model (`Electric Piano`)
Physical model of a struck metal tine/reed and magnetic pickup, featuring independent hammer hardness, tine decay, bell chime, and pickup symmetry.
- **Row 1**: Model, Hammer Force, Force Velocity, Hammer Width, Width Key Track.
- **Row 2**: Hammer Noise, Tine Decay, Release Decay, Tone Bar Level, Overtone Tune.
- **Rows 3–4**: Overtone Ratios & Levels, Bell Level, Bell Velocity, Pickup Position, and Pickup Mod Source & Int.

### 10. Brass Model (`Brass Model`)
Physical model of a lip-reed brass instrument (trumpet, trombone, French horn, synth brass) responding organically to breath pressure and lip tension.
- **Row 1**: Model, Instrument Type (`Trumpet`, `Trombone`, `Horn`, etc.), Bell Tone, Lip Character, Key Track.
- **Row 2**: Pressure Envelope / Source, Pressure Level, Vel Int, Mod1 Source & Int, Mod2 Source & Int.
- **Row 3**: Lip Pitch Offset, Pressure-to-Pitch Interaction, Breath Noise Level.
- **Rows 4–5**: Internal Pressure Envelope (`Attack`, `Decay`, `Break`, `Slope`, `Sustain`), Pitch LFO (Vibrato) Int, and Bell Resonance Eq.

### 11. Reed Model (`Reed Model`)
Physical model of single- and double-reed woodwinds (saxophone, clarinet, oboe, bassoon, flute/panpipe) with dynamic reed stiffness and bore reflection.
- **Row 1**: Model, Instrument Preset (`AltoSax`, `TenorSax`, `Clarinet`, `Oboe`, `Flute`, etc.), Bore Tone, Reed Character, Key Track.
- **Row 2**: Breath Pressure Source, Pressure Level, Vel Int, Mod1 Source & Int, Mod2 Source & Int.
- **Row 3**: Reed Pitch Interaction, Saturation/Growl, Breath Noise.
- **Rows 4–5**: Internal Breath Pressure Envelope (`Attack`, `Decay`, `Break`, `Slope`, `Sustain`), Vibrato LFO Int, and Formant Resonance.

### 12. Plucked String Model (`Plucked String`)
Physical waveguide model of a plucked acoustic, nylon, electric guitar, harp, shamisen, or bass string.
- **Row 1**: Model, Attack Wave (plectrum/finger type), String Loss (brightness), String Damping (sustain), Dispersion (inharmonicity).
- **Row 2**: Attack Level, Vel Int, Key Track, Decay Mod Source & Int.
- **Row 3**: Pluck Position (bridge to neck), Position Vel Int, Position Key Track, Pickup Position, Pickup Toggle.
- **Row 4**: Harmonic/Mute simulation and Body Formant EQ.

### 13. Bowed String Model (`Bowed String`)
Physical waveguide model of a bowed violin, viola, cello, or contrabass where bow speed, bow pressure, and bow position interact dynamically.
- **Row 1**: Model, String Loss, String Damping, Dispersion, Bow Resonance.
- **Row 2**: Bow Speed Source, Speed Level, Vel Int, Mod1 Source & Int, Mod2 Source & Int.
- **Row 3**: Bow Pressure, Pressure Vel Int, Pressure Mod Source & Int, Bow Position (Sul Ponticello to Sul Tasto), Position Mod Source & Int.
- **Rows 4–5**: Internal Bow Speed Envelope (`Attack`, `Decay`, `Break`, `Slope`, `Sustain`), String Scratch Noise, and Body Resonance EQ.

## Saving & Loading OSC 1 Presets

To save your current OSC 1 setup as a reusable preset—or load one of 8 saved presets for the active synthesis model—tap **OSC Common** in the top-right corner and open the **OSC Presets** drawer on [Page 3: OSC Common](https://github.com/timandtheocean/e1-korg-z1/tree/main/usermanual/pages/03b-osc-common.md).
